# Path2Devhub

> Building software from first principles.

This repository serves as the public entry point for **Path2Devhub**.

Path2Devhub is an independent software engineering space focused on understanding how software systems work by building and exploring them from the ground up.

The work spans practical engineering, computer science fundamentals, and system-level exploration.

## Areas of Exploration

- Systems & Database Internals
- Compilers & Programming Languages
- AI Computation
- Backend & Distributed Systems
- Software Architecture

## Public Repositories

Selected utilities, developer tools, experiments, and reusable projects will be published here as they reach a useful and stable state.

More public work will be added over time.

## Main Projects

Path2Devhub also contains larger engineering projects involving areas such as:

- Database engines
- Compiler development
- AI computation
- Distributed systems
- Backend architecture

Some of these projects are currently maintained in private repositories while they are under active development and architectural refinement.

## Engineering Notes

Technical decisions, architecture exploration, implementation trade-offs, and lessons learned are documented on the Path2Devhub website.

The goal is not only to build software, but to understand the systems and design decisions behind it.
